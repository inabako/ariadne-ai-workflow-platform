# Infrastructure Boilerplates

IaC and shared infrastructure templates live here.

| Template | Purpose |
| --- | --- |
| `microservice-infra-template/` | Realtime gateway infrastructure |
| `platform-infra-template/` | Development, CI/CD, and observability platform infrastructure |
| `database-infra-template/` | PostgreSQL / MySQL shared database infrastructure |
| `middleware-infra-template/` | Redis shared middleware infrastructure |
| `identity-infra-template/` | OpenLDAP identity / directory infrastructure |
| `opentelemetry-collector-template/` | OpenTelemetry Collector receiver / processor / exporter infrastructure |
