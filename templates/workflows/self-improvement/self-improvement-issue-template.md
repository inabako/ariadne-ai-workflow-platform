# Self-Improvement Issue

## Summary

Workflow Feedbackから抽出した改善内容を簡潔に記載してください。

## Background

どのWorkflow実行中に、どのような摩擦、ノイズ、やりづらさが発生したかを記載してください。

## Problem

何が問題だったのかを記載してください。

## Impact

品質、効率、AIの迷い、Human Check負荷、token使用量、保守性への影響を記載してください。

## Proposed Change

実施する改善案を記載してください。

## Scope

変更対象のWorkflow、Agent、Docs、Runtime、RAG、Dispatcher等を記載してください。

## Ariadne Fit Check

- [ ] AIが迷わない環境に寄与するか
- [ ] 認知負荷を下げるか
- [ ] 品質を支える仕組みになるか
- [ ] 維持しやすいか
- [ ] 改善しやすいか
- [ ] 運用可能か
- [ ] 責務を曖昧にしないか
- [ ] Human Responsibilityを曖昧にしないか
- [ ] Ariadneの思想と矛盾しないか

## Acceptance Criteria

- [ ] 改善対象が明確である
- [ ] Ariadneの設計思想に反していない
- [ ] AIが迷わない環境に寄与している
- [ ] Human Responsibilityを曖昧にしていない
- [ ] 既存Workflowを壊していない
- [ ] 必要なDocsが更新されている
- [ ] 必要なテストが追加または更新されている
- [ ] Evidenceが保存されている
