# Changelog

All notable changes to ARIADNE will be documented in this file.

This project follows reviewable release notes. Dates use `YYYY-MM-DD`.

For the Japanese version, see [CHANGELOG.md](CHANGELOG.md).

## [Unreleased]

### Added

- OSS release foundation documents, citation metadata, release checklists, and release validation tooling.
- Architecture overview documents for `aiwfctl`, runtime, workflow dispatch, state, artifacts, evidence, Human Gates, and recovery.
- AGPL-3.0-or-later license policy, legal boundary documents, and release validation support.

### Changed

- Root README now links to OSS publication, release, citation, contribution, security, and license guidance.
- Ariadne workflow assets were moved from `.github/` to `.ariadne/`, keeping `.github/` focused on GitHub platform configuration.

### Security

- Added release validation that checks required public-release files and flags common private data patterns.
