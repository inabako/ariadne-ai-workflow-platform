# ライセンスFAQ

## ARIADNEは商用利用できますか

ARIADNEは `AGPL-3.0-or-later` で公開する方針です。商用利用そのものを禁止する方針ではありませんが、利用、改変、配布、network提供の形態に応じてAGPL上の義務を確認してください。

## ARIADNEで生成したcodeはAGPLになりますか

ARIADNEをtoolとして使用したという理由だけで、生成codeへARIADNE repository licenseを自動適用する方針ではありません。

## ARIADNEで生成したdocumentやarticleはAGPLになりますか

tool利用だけを理由とした自動的なlicense propagationは意図していません。ただし、利用者はinput rights、third-party license、AI model terms、適用法令を確認する必要があります。

## 生成artifactへ別licenseを適用できますか

想定方針では、利用者は適用される義務に従い、生成artifactのlicenseを選択できます。

## 生成出力にARIADNE source codeが含まれる場合はどうなりますか

ARIADNE source codeまたは保護対象materialが出力の一部としてcopy、embedded、linked、distributedされる場合、別途license上の義務が生じる可能性があります。

## `or-later` とは何ですか

`AGPL-3.0-or-later` では、利用者はlicense termsの範囲で、GNU Affero General Public License version 3またはFree Software Foundationが公開する後継versionを選択できます。

## ARIADNEの名称やlogoもsoftware licenseの対象ですか

いいえ。trademarkとbrandingの利用は [商標とブランド利用](../brand/trademarks.md) で別途扱います。
