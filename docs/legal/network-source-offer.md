# Network Source Offer

この文書は、ARIADNEをAGPLで公開する場合のnetwork source distribution obligationを検討するための文書です。

## 現在の状態

repository licenseは `AGPL-3.0-or-later` です。

## Network提供時の確認

改変版ARIADNE serviceをnetwork越しに提供する前に、そのserviceとやり取りするuserへcorresponding sourceをどのように提供するかを確認します。

projectでは次を文書化します。

- source codeの提供場所。
- 稼働しているversionまたはcommit。
- userがcorresponding sourceを取得する方法。
- 含まれるbuild materialとdeployment material。
- 除外される、または別licenseで扱われるthird-party component。

この文書は法的助言ではありません。
