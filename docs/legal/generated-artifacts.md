# 生成Artifact

ARIADNEは、次のようなartifactを生成または変換する場合があります。

- source code。
- test code。
- requirements documentとdesign document。
- review report。
- research note。
- Markdown、JSON、YAML、XML、configuration file。
- image、diagram、prompt output。
- project scaffold。

ARIADNEをtoolとして使用したという理由だけで、生成artifactへARIADNE repository licenseを自動適用する方針ではありません。

生成artifactのlicenseは、利用者の判断、適用法令、input material、third-party license、利用したAI modelまたはexternal serviceの規約に依存します。

## 境界

この方針は、すべての生成出力が常にARIADNEのlicense対象外である、という意味ではありません。ARIADNE source codeまたは保護対象repository materialが出力の一部としてcopy、embedded、linked、distributedされる場合、そのcopyまたは結合materialには別途義務が生じる可能性があります。
