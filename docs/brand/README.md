## Brand Principle

Ariadne は、AI を万能に見せるためのplatformではありません。

AIが迷いやすい前提に立ち、Context、RAG、Evidence、Human Check、Doctor、Dispatcher、Manifestを一本の糸として結びます。

迷宮を消すのではなく、迷宮を歩けるようにする。

それが Ariadne AI Workflow Platform のbrand coreです。
