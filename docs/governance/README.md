# Governance

このディレクトリは、Ariadne AI Workflow Platform の governance 入口です。

現在の governance は次の2階層に分けます。

| Area | Path | Purpose |
| --- | --- | --- |
| Ariadne Governance | [ariadne/README.md](ariadne/README.md) | Ariadne 自体の Mission、責任境界、改善判断、Platform Fit Check |
| Implementation Governance | [implementation/README.md](implementation/README.md) | Ariadne が生成・変更・保守する成果物の実装規約 |

## 運用方針

- Ariadne の思想、責任境界、自己改善方針は `ariadne/` に置きます。
- 実装、言語、テンプレート、AI Agent の成果物品質に関わる規約は `implementation/` に置きます。
- AI workflow が Issue 化や設計判断を行う前には、まず Ariadne Governance を確認します。
- 実装に入る段階では、対象成果物に応じて Implementation Governance を参照します。
